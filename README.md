## Featured Project

### BreadBread (빵빵)
**AI-powered Bakery Tour Recommendation Platform**

대전 지역 베이커리 정보를 바탕으로 사용자의 취향과 조건에 맞는 빵투어 코스를 추천하는 웹 서비스입니다.

사용자의 예산, 이동 방식, 선호 카테고리, 동행 유형, 대기 허용도 등을 고려해 방문 코스를 구성하고, 베이커리 관련 데이터와 AI 워크플로를 활용해 더욱 유연한 여행 경험을 제공하는 것을 목표로 합니다.

#### My Responsibilities

**Frontend Development**
- 사용자와 상호작용하는 웹 서비스의 프론트엔드 개발
- AI 기반 코스 추천 기능과 서비스 화면 간의 연동

**AI Development**
- n8n과 Dify를 활용한 AI 워크플로 구성
- 사용자 조건을 반영한 코스 생성 및 큐레이션 기능 구현
- 외부 데이터 수집 및 AI 추천 기능을 연결하는 워크플로 설계

#### Key Features

- **Personalized Tour Courses:** 사용자의 취향, 예산, 이동 방식 등을 고려한 베이커리 코스 추천
- **AI Course Generation:** 사용자 입력 조건을 기반으로 방문 코스 생성
- **Alternative Destination Recommendation:** 혼잡 상황 등을 고려한 대체 방문지 제안
- **Bakery Information Integration:** 외부 API를 활용한 베이커리 정보 연동
- **Trend-based Congestion Analysis:** 웹에서 수집한 베이커리 관련 정보를 혼잡도 분석에 활용

#### AI Architecture

프로젝트에서는 n8n과 Dify를 중심으로 AI 워크플로를 구성했습니다.

| Component | Description |
|---|---|
| Course Agent | 사용자 조건을 고려한 코스 생성 |
| Curator Agent | 생성된 코스를 큐레이션하고 방문지 추천을 보완 |
| Trend Collector | 웹 데이터를 수집해 대기, 웨이팅, 오픈런, 품절 등 혼잡 관련 정보를 분석에 활용 |
| n8n | 워크플로 실행 및 외부 서비스 간 연동 |
| Dify | 프롬프트와 LLM 기반 AI 기능 관리 |
| Apify | 웹 데이터 수집 |
| Kakao Local API | 베이커리 위치 및 장소 정보 연동 |

#### Technologies Used

- **Frontend:** 프로젝트 프론트엔드 개발
- **AI Orchestration:** n8n, Dify
- **Data Collection:** Apify
- **External API:** Kakao Local API
- **Analytics:** Google Analytics 4 (GA4)
